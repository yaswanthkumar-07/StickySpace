# 🌳 StickySpace

StickySpace is a modern sticky-note productivity web app that helps users organize ideas, tasks, and goals in a visual workspace.

## ✨ Features

* 📝 Create colorful sticky notes
* ✅ Multi-line task management
* 🔍 Search notes instantly
* 🏷️ Category-based organization
* ⭐ Favorite important notes
* 🌳 Idea Tree progress system
* 🎨 Multiple note colors
* 🔤 Font customization
* 💾 Local Storage persistence
* 📱 Responsive design

## 🚀 Live Demo

https://stickyspace.pages.dev

## 🛠️ Built With

* React.js
* JavaScript
* CSS3
* Local Storage API
* Cloudflare Pages

## 📸 Project Idea

StickySpace combines the simplicity of sticky notes with task tracking and visual progress. Users can capture ideas, manage tasks, and grow their Idea Tree as they complete work.

## ⚙️ Installation

```bash
git clone https://github.com/yaswanthkumar-07/StickySpace.git
```
